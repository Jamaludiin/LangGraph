Agent Details

Each agent is specialized for a specific task in the test generation pipeline

01

Code Reader Agent

Reads the source code from the program under test and loads it into the agent state for processing by downstream agents.

Inputs
File Path (put.py)
Outputs
code_under_test: str
02

Static Code Analyzer Agent

Analyzes the code to extract function signatures, branches, loops, input types, external dependencies, and potential edge cases. Outputs a structured code summary.

Inputs
code_under_test
Outputs
static_analyzer: str
03

Test Plan Agent

Generates a comprehensive test plan including both positive and negative test cases based on the analyzed source code.

Inputs
code_under_test
Outputs
test_plan: str
04

Test Plan Reviewer Agent

Reviews the generated test plan to detect missing edge cases, validate logic, ensure completeness, and verify adherence to testing best practices.

Inputs
test_plan
Outputs
test_plan_reviewer: str
05

Test Case Generator Agent

Generates pure Python pytest-style test cases including necessary imports and comments based on the test plan and source code.

Inputs
code_under_test test_plan
Outputs
test_case: str
06

Test Case Optimizer Agent

Refactors the test code to ensure pytest naming conventions, removes unnecessary mocks, validates imports, and improves readability.

Inputs
test_case
Outputs
test_case_optimizer: str
07

Mutational Testing Agent

Creates mutations of the original code (changing operators, removing checks, etc.) and ensures tests catch those mutations for strong coverage.

Inputs
code_under_test static_analyzer test_plan test_case patch_suggestion
Outputs
mutational_testing: str
08

Coverage Enhancer Agent

Analyzes test coverage to identify missing branches, error paths, and untested input types. Suggests additional tests to improve coverage.

Inputs
code_under_test test_plan test_case static_analyzer patch_suggestion execution mutational_testing bug_predictor
Outputs
coverage_enhancer: str
09

Documentation Generator Agent

Generates comprehensive test documentation including test reports, logic explanations, and mapping of tests to functions.

Inputs
All state fields
Outputs
documentation_generator: str
10

Bug Predictor Agent

Inspects code to predict potential defects using static heuristics: division by zero, missing validation, unsafe conversions, and more.

Inputs
code_under_test static_analyzer test_plan test_case
Outputs
bug_predictor: str
11

Execution Agent

Executes the generated test cases and returns failures for analysis. Can trigger re-generation when tests fail.

Inputs
test_case
Outputs
execution: str
12

Patch Suggestion Agent

Analyzes test failures to propose code fixes and explain root causes. Transforms the system into an autonomous debugging assistant.

Inputs
execution
Outputs
patch_suggestion: str

Workflow Architecture
